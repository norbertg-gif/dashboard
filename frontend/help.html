1. Prihlásenie a prístup

  • Dashboard je chránený HTTP Basic auth (používateľ + heslo). Prehliadač vyzve na prihlásenie pri prvom načítaní.
  • Verejné API (/api/public/*) používa token namiesto hesla — pre externý prístup.
  • Prevádzka beží na Render.com; po prihlásení sa dashboard načíta na svojej URL.

3. Záložky

  • 📈 Grafy — mriežka panelov s grafmi tickerov z watchlistu. Klik aktivuje panel.
  • 📊 Portfólio — eToro pozície, summary (invested / equity / P&L).
  • História — uzavreté obchody a journal.
  • Risk — riziková analýza portfólia.
  • 📈 Prediktívny — predikcia ďalšej sviečky + denné/týždenné buy signály.
  • Scanner — Nasdaq skener s DIP crossover stratégiou.

Pravý panel

  • Daily buy signál
    • Weekly bias — BULLISH / BEARISH-NEUTRÁLNY: composite > 5 %, cena nad Kumo, EMA10 > EMA20.
    • Dnešné skóre 0–4 — počet splnených denných podmienok. Dnešný signál je aktívny len pri bullish weekly bias.
    • História signálov — minulé signály a výsledok voči aktuálnej cene (win/loss/flat/pending). Farba skóre = tier.
  • Opportunities — najsľubnejšie tickery podľa setup skóre.
  • Prognóza nasledujúcej sviečky — Smer (BULLISH/BEARISH + % zmena), Regime (HMM: Bull/Bear/Sideways/High volatility — diagnostika, nezasahuje do ML), Open/High/Low/Close, Composite signal, ML bull prob, ML accuracy.
  • Technická vstupná zóna — len technický odhad vstupu.
  • Backtesting — celková správnosť, priemerná chyba, vs. default váhy.
  • Hit rate / Váhy indikátorov — výkonnosť a váhy indikátorov.

Ľavý mini panel

  • DAILY — mini graf so signálmi.
  • SIGNAL HISTORY — časová os signálov s win rate.
  • TIMEFRAME ALIGNMENT — Weekly bias, Weekly trend, Daily trend, Daily signal → PLNÁ ZHODA BULL / BEAR / ZMIEŠANÉ.

Farby signálov (tier)

O farbe rozhoduje kontext trendu, nie hrubé skóre:

FarbaTierVýznam
zelenáBuyDip v uptrende (EMA10 > EMA20) — kupovateľný podľa DIP stratégie.
oranžováWatchSideways / prechod — sleduj, trend ešte nepotvrdený.
červenáCounterDip počas downtrendu (EMA10 < EMA20 a cena pod EMA20) — proti-trendový, „falling-knife" riziko.

Číslo x/4 na markeri = sila (koľko podmienok). Farba povie či kupovať, číslo ako silný signál je.

Historické signály sa neprepisujú — staré záznamy bez tieru sa dočasne zobrazia ako watch a prefarbia sa po novom vyhodnotení tickera.

5. Scanner + DIP stratégia

Záložka Scanner prechádza Nasdaq-100 a hľadá denné buy signály, ktoré kombinuje s externým DIP rankingom (importovaný Excel).

Ovládanie

  • Vybrať súbor → Import DIP Excel — nahrá DIP ranking (FA/TA) z XLSX.
  • Spustiť scanner — paralelný sken Nasdaq-100 (progress bar, beží na pozadí).

Watch vs. Buy

Signál sa zaznamenáva od 2/4 podmienok. Či je buy/watch/counter rozhoduje trendový kontext (viď farby vyššie), nie len počet podmienok.

6. Filozofia signálov

Štyri denné podmienky (c1–c4)

KódPodmienkaPrah
c1Dotyk EMA20 alebo Kijunvzdialenosť < 0,5 %
c2RSI pullbackRSI < 45
c3Bullish sviečka s objemomclose > open a objem > 1,2× priemer
c4Štatistický dip (z-score)60-dňový rolling z-score ≤ −1,5

z-score meria, ako veľmi je cena „lacná" voči vlastnému 60-dňovému priemeru. Nie je samostatný indikátor — prejaví sa v skóre x/4 a v stĺpci Reason.

Trend-primárne určenie tieru

Skóre = koľko podmienok (sila). O farbe/tieri rozhoduje trend:

  • Uptrend (EMA10 > EMA20) → buy — aj pri 2/4. Jadro DIP stratégie.
  • Downtrend (EMA10 < EMA20 a cena pod EMA20) → counter — proti-trendový dip.
  • Sideways / prechod → watch.

Jednotný scoring (single source of truth)

Scanner aj prediktívny graf používajú tú istú funkciu skórovania — pre ten istý ticker ukazujú rovnaké hodnoty.

Nie je to „falling-knife" lovenie dna — systém zámerne odlišuje dipy v uptrende (kupovať) od dipov v páde (vyhnúť sa).

7. Presety, watchlist, eToro

  • Watchlist — sledované tickery (Grafy, Opportunities, prefetch).
  • Presety — uložené rozloženia (watchlist + panely). Ulož cez „Ulož ako…", načítaj cez „PRESET".
  • eToro pozície — Portfólio tab ukazuje živé pozície a P&L. Equity sa počíta jednotne ako cash + invested + total_pnl.

9. Technická príloha

Pre údržbu. Detailné pravidlá a pasce sú v CLAUDE.md.

Stack

  • Backend: FastAPI (Python 3.11), Uvicorn, pandas/numpy, scikit-learn, yfinance, hmmlearn.
  • eToro proxy: stdlib HTTPServer na localhost:8765, background thread (nie samostatný proces v produkcii).
  • Frontend: vanilla HTML/CSS/JS, Lightweight Charts 4.1.3, SheetJS — bez build kroku.
  • Storage: /data (Render disk) — presets, journal, signal/weights logy, cache/{ohlcv,portfolio,instruments}.

Auth

  • Globálny _BasicAuth middleware vynucuje Basic auth na všetkom okrem /api/public/*. Bez DASH_USER je auth vypnutá (lokál). V produkcii (RENDER=1) fail-closed.
  • /help je teda automaticky chránené Basic auth.

Signal scoring — kde žije

  • score_signal_day(row, zscore) — jediný zdroj pravdy pre c1–c4 + per-bar trend.
  • rolling_zscore(close) — 60-dňový rolling z-score.
  • signal_tier(score, trend) — mapuje trend na buy/watch/counter.
  • build_setup_assessment(...) — setup skóre (counter = risk, nie pozitívum).
  • Volané z _scan_buy_signal_for_ticker aj predictive endpointu — rovnaká logika.

Dátové toky

  • OHLCV cache inkrementálna — cache/ohlcv/{SYMBOL}_{INTERVAL}.gz, až 1000 sviečok, doťahuje len tail.
  • Portfolio cache TTL = 120 s RAM, fallback na disk pri výpadku proxy.
  • WebSocket (wss://ws.etoro.com/ws) ženie živé ceny; REST refresh každých 15 s ako fallback.
  • Background prefetch (/api/prefetch) zahrieva cache pri štarte.

Deploy

  • Render auto-deploy z vetvy main — push spustí redeploy.
  • Perzistentný disk /data; logy a cache sa necommitujú (.renderignore).
